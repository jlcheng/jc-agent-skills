# Implement Build

Read the approved tech spec and implement its scope, following the user's and repository's
instructions. Complete appropriate checks before handing the implementation to Review.

Use the shared run directory and follow the
[persistent record guide](../implement/references/records.md). Keep Build progress, implementation
identity, checks, and any blockers or pending decisions in `review.md` so another session can
continue. At handoff, record what is ready for Review and any remaining limitations.

Building does not itself authorize commits, publication, or deployment.

# Written result template

The written result is a short document the user comes back to, and usually hands to an AI to build.
Write it in the confirmed domain vocabulary. It must make sense to someone who never saw the
conversation.

```markdown
# <name of the thing>: design

## Summary

<At most four sentences. What the thing is, who it's for, and what it does.>

## Details

<What a builder needs to know: parts, behavior, layout, examples. As long as it needs to be and no
longer.>

## Decisions

- **<The decision, stated as a fact.>** <Why, including options that were rejected when that helps.>

## Not in scope

- <What this deliberately leaves out, so a builder doesn't add it.>
```
